EXTERNAL DECODER — ffmpeg
STATUS—

未設定

ffmpeg を指定すると、標準では読めない形式（mp4 / m4a / webm / mkv / mov / opus など）も読み込めるようになります。まず内蔵デコーダで試し、 失敗したときだけ ffmpeg に回すので、指定しなければ今までどおりの動作です。
ffmpeg 本体は同梱していません。winget install ffmpeg などで入れて PATH が通っていれば自動検出できます。

EXPERIMENTAL — élastique OUTSIDE REAPER
STATUS—

未設定

REAPER Shifter は本来 REAPER 上でしか動きませんが、REAPER に同梱の elastique3.dll を直接読み込むことで他のホストでも Natural / Manual の キャッシュ経路だけ使えるようにする実験的な機能です。
DLL は zplane 社のライセンス品で再配布できません。REAPER をインストール済みの 環境で、自分の PC 上にあるものを指定してください。動作は無保証です。
制限: モードは Soloist 固定、フォルマントと Manual ストレッチは効きません（±2 オクターブ超と ストレッチ指定時はキャッシュを作らず Varispeed 再生になります）。
